# コンピュータサイエンス・サマーキャンプ ゲームプログラミングコース（インストラクター）

## Overview

高校生向け「コンピュータサイエンス・サマーキャンプ」にて、2023年および2024年の2年連続でJavaScriptゲームプログラミングコースの専属インストラクターを担当しました。本プログラムの目的は、プログラミング未経験の高校生にICT技術の楽しさを伝え、自発的な興味を引き出すことです。私は4〜5名の高校生チームを主導し、3泊4日という限られた工期の中で、JavaScript、HTML5、CreateJSを用いてシューティングゲームの企画から要件定義、開発、リリースまでを一貫して牽引しました。その結果、参加した高校生から「ICT技術への関心が高まった」「プログラミングの面白さが分かった」という評価を多数獲得しています。

## Management Approach

本コースにおける最大の課題は、プログラミング未経験者にいかにして「自分で作った」という達成感とプログラミングの楽しさを実感させるかという点でした。ロジック実装をすべて任せるのは技術的に現実的ではなく、逆にインストラクターが全てのコードを書くだけでは参加者の主体性が失われてしまいます。そこで私は、実際のシステム開発における分業体制を参考に、高校生が主体的に関与でき、かつゲームのコア体験に直結する「ゲームバランスの調整」と「ゲームデザイン」の役割を参加者に委任する設計を取り入れました。

ロジックの実装はインストラクターである私が担い、難易度を決定づける変数の調整を高校生に任せています。以下のコードのように数値を変更することでソフトウェアの挙動が変わるという、プログラミングの本質的な面白さを安全に体験できる環境を構築しました。

```javascript
// Easy モードの設定例 — 高校生がパラメータを調整・テストプレイした部分
if (mode === 'easy') {
    enemy_spown_time          = 60;   // 敵の出現間隔（フレーム数）
    strong_enemy_spown_time   = 150;  // 強敵の出現間隔
    strong_enemy_hobbor_frame = 120;  // 強敵がホバリングするフレーム数
    life                      = 5;    // プレイヤーのライフ
    remain_ballet             = 5;    // 残弾数
    enemy_norma               = 20;   // クリアに必要な撃破数
    remain_time               = 25;   // 制限時間（秒）
}
```

また、ゲームデザイン担当の生徒には、自ら考えた世界観に合わせてBGMや効果音、画像素材を選定してもらいました。指定したファイル名を実際のコードに組み込む工程を共に体験することで、制作の全体フローを俯瞰できるように工夫しています。

## Technical Solutions

このコースでの技術的な課題に対し、インストラクター初年度と次年度で段階的なアプローチを取りました。

### 2023年度：制作フロー全体の体験を最優先とした基盤構築
2023年度はインストラクター初年度であったため、まずは高校生に「ゲーム制作の流れ全体を体験してもらうこと」を最優先としました。テンプレートとして用意されていたシューティングゲームをベースにしつつ、ロジックの実装では全方位から敵が出てくるスリルを演出しました。その上で、BGMや効果音、敵キャラクターの画像といった素材を高校生と共に選定し、ゲームに組み込むアプローチをとることで、ゲームデザインの基礎を作り上げることに注力しました。

### 2024年度：前年度の知見を活かした要件定義と機能拡張
2024年度は前年度の経験から得た知見を活かし、高校生の「もっと面白くしたい」という抽象的なアイデアを技術的に実現するための機能拡張を行いました。例えば、「不規則で手強い敵を出したい」という要望に対しては、単調な直進だけでなくプレイヤーを追いかけ、一定時間後に散開するベクトル演算を用いた追尾AIを新たに設計・実装しました。以下のコードのように、プレイヤーの座標を取得してベクトルを正規化し、速度を乗算することで滑らかな追尾を実現しています。

```javascript
// 追尾フェーズ：プレイヤー方向へのベクトル正規化による移動
let deltaX = playerX - enemyX;
let deltaY = playerY - enemyY;
let distance = Math.sqrt(deltaX * deltaX + deltaY * deltaY);
enemy.x += (deltaX / distance) * enemySpeed;
enemy.y += (deltaY / distance) * enemySpeed;
```

また、「やり込み要素と戦略性が欲しい」という声に応え、EasyからHard、さらに隠し要素の「裏モード」を加えた4段階の連動型難易度システムと、弾数制限およびキー入力によるリロード機構を導入しました。10種類のパラメータが難易度ごとに連動して変化するアーキテクチャを設計し、無限に攻撃できる仕様を廃止することで駆け引きの要素を技術的に実現しています。さらに没入感を高めるため、被ダメージ時に画面を赤くフラッシュさせるエフェクト処理や、難易度・モード遷移に応じたBGM・SEの動的切り替え機能も実装しました。

## Key Competencies
## この経験で得たもの

このインストラクター経験を通じて、私は主に三つの力を養うことができました。

一つ目はプロジェクト推進力です。3泊4日という限られた期間の中で、企画の段階から実際にプレイできる完成品に至るまで、グループ全体をゴールへ導く経験を積みました。

二つ目は要件定義・設計力です。高校生から出てくるアイデアは抽象的なものが多く、漠然とした要望を、実装可能な仕様に落とし込む作業が求められました。この過程は、実際のシステムエンジニアがクライアントの要望を技術仕様に変換する業務と共通するものであり、SE的な視点を養う貴重な経験となりました。

三つ目はコミュニケーション力です。プログラミング未経験の高校生に対して、コードの意味や動作の仕組みをかみ砕いて説明し、ただ教えるのではなく主体的な参加を引き出すことが求められました。相手の理解度に合わせて説明を調整する力が身につきました。
