# コンピュータサイエンス・サマーキャンプ ゲームプログラミングコース（インストラクター）

## 概要

高校生向け「コンピュータサイエンス・サマーキャンプ」のJavaScriptゲームプログラミングコースにて、2023年・2024年の2年連続でインストラクターを務めています。このキャンプは、高校生にICT技術への興味を持ってもらうことを目的としたプログラムであり、JavaScriptゲームプログラミングコースとCGコースの二つから構成されています。私が担当するゲームプログラミングコースでは、3泊4日という短い期間の中で、プログラミング未経験の高校生4〜5名のグループと共にシューティングゲームの企画・開発・完成までを一貫して支援する形です。使用言語はJavaScriptとHTMLで、フレームワークにはCreateJSを採用しています。

## 課題と取り組み

このコースで最も大きな課題は、プログラミング未経験の高校生に対して、どのようにすればプログラミングの楽しさを実感してもらえるかという点にあります。ロジック実装を全て高校生に任せることは技術的に現実的ではありません。しかし、インストラクターがすべてのコードを書き、高校生はそれを眺めるだけという形では、「自分で作った」という実感や達成感が得られず、ICT技術への興味にもつながりません。

この課題に対して、私は実際のシステム開発における分業体制を参考に役割分担を設計しました。具体的には、高校生が主体的に関われる領域として「ゲームバランスの調整」と「ゲームデザイン」の二つの役割の分担です。

ゲームバランスの調整では、高校生から出てきたアイデアに対して、ロジック部分の実装はインストラクターである私が引き受け、難易度を左右するパラメータの調整とテストプレイを高校生に委ねています。例えば2024年度では、敵の出現間隔、敵のホバリング時間、プレイヤーのライフ、残弾数、クリアに必要な撃破数、制限時間といったパラメータを、Easy・Normal・Hardの各難易度ごとに高校生自身に調節していただきました。

```javascript
// Easy モードの設定例 — 高校生がパラメータを調整した部分
if (mode === 'easy') {
    enemy_spown_time              = 60;   // 敵の出現間隔（フレーム数）
    strong_enemy_spown_time       = 150;  // 強敵の出現間隔
    strong_enemy_hobbor_frame     = 120;  // 強敵がホバリングするフレーム数
    life                          = 5;    // プレイヤーのライフ
    remain_ballet                 = 5;    // 残弾数
    enemy_norma                   = 20;   // クリアに必要な撃破数
    remain_time                   = 25;   // 制限時間（秒）
}
```

各パラメータの意味をかみ砕いて説明しながら、値を変えるとゲーム体験がどのように変わるかを実際にプレイして確かめてもらうことで、コードを変えると動きが変わるプログラミングの本質的な面白さを伝えました。

もう一つのゲームデザイン担当では、どうすればより「遊びたい」と思えるゲームになるかを高校生自身に考えてもらい、その世界観に合ったBGM・効果音・敵キャラクターの画像・背景などを選定して頂きました。そして、実際にファイル名を決めてもらい、そのアセットをコード上に組み込む作業まで体験してもらうことで、ゲーム制作の全体像を伝えました。

こうした取り組みの結果、参加した高校生から「ICT技術について興味を持った」という声を多数頂くことができました。

## ゲームの技術的な工夫点

### 2023年度

2023年度はインストラクター初年度であったため、テンプレートとして用意されていたシューティングゲームをベースに、高校生と一緒にゲームデザインの部分を作り上げることに注力しました。ロジックの実装では全方位から敵が出てくるスリルを作りつつさらに、BGM・効果音・敵キャラクターの画像といった素材を高校生と共に選定し、ゲームに組み込むことで、まずはゲーム制作の流れ全体を体験してもらうことを最優先としました。

### 2024年度

2024年度は、2023年度の経験から得た反省と知見を活かし、高校生の「もっと面白くしたい」というアイデアを技術的に実現するために、インストラクターとして以下のような機能を設計・実装しました。

まず、難易度システムについてです。Easy・Normal・Hardの3段階に加え、隠し要素「裏モード」を含む4段階の難易度を実装しました。各難易度では、敵の出現頻度、強敵の移動速度、プレイヤーのライフ、残弾数、クリア条件、制限時間など10種類のパラメータが連動して変化する設計としており、難易度ごとに異なるゲーム体験が得られるようにしました。

次に、敵のAIについてです。2023年度は画面上で直進するだけの単純な敵のみでしたが、2024年度ではプレイヤーを追尾する強敵を新たに実装しました。この強敵は、出現後の一定フレーム数の間はプレイヤーとの距離方向に追尾し続け、ホバリング時間が経過すると3体がそれぞれ異なる方向（左上・左・左下）へ高速で離脱するという動きをします。この追尾と散開を組み合わせた挙動により、敵の動きを予測して立ち回る戦略性が求められるようになりました。

```javascript
// 追尾フェーズ：プレイヤー方向へのベクトル正規化による移動
let deltaX = playerX - enemyX;
let deltaY = playerY - enemyY;
let distance = Math.sqrt(deltaX * deltaX + deltaY * deltaY);
enemy.x += (deltaX / distance) * enemySpeed;
enemy.y += (deltaY / distance) * enemySpeed;
```

さらに、残弾とリロードの仕組みも導入しました。シューティングゲームの駆け引きとは何で生まれるかを高校生と一緒に考えて、弾を撃ち尽くした場合にはENTERキーと左クリックの同時押しによるリロード操作を加える設計です。こうして無限に撃ち続けることができないため、弾数を管理しながら戦うという戦略的な要素が加えました。

演出面では、敵との接触時に画面全体を赤くフラッシュさせる被ダメージ演出を実装し、プレイヤーが受けたダメージを視覚的にフィードバックすることでゲームとしての臨場感を高めました。また、各難易度ごとに異なるBGMを再生する仕組みを取り入れ、裏モードでは専用の決定音を鳴らすなど、高校生がデザインした音響演出をコードに反映しました。

## この経験で得たもの

このインストラクター経験を通じて、私は主に三つの力を養うことができました。

一つ目はプロジェクト推進力です。3泊4日という限られた期間の中で、企画の段階から実際にプレイできる完成品に至るまで、グループ全体をゴールへ導く経験を積みました。

二つ目は要件定義・設計力です。高校生から出てくるアイデアは抽象的なものが多く、「不規則な敵の動きを作りたい」等の漠然とした要望を、実装可能な仕様に落とし込む作業が求められました。この過程は、実際のシステムエンジニアがクライアントの要望を技術仕様に変換する業務と共通するものであり、SE的な視点を養う貴重な経験となりました。

三つ目はコミュニケーション力です。プログラミング未経験の高校生に対して、コードの意味や動作の仕組みをかみ砕いて説明し、ただ教えるのではなく主体的な参加を引き出すことが求められました。相手の理解度に合わせて説明を調整する力が身につきました。
