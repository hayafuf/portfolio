# コンピュータサイエンス・サマーキャンプ ゲームプログラミングコース（インストラクター）

## Overview

高校生向け「コンピュータサイエンス・サマーキャンプ」にて、2023年および2024年でJavaScriptゲームプログラミングコースの専属インストラクターを担当しました。本プログラムの目的は、高校生にICT技術の楽しさを伝え、興味を引き出すことです。私は4〜5名の高校生チームを主導し、3泊4日という限られた日程の中で、JavaScript、HTML5、CreateJSを用いてシューティングゲームの拡張機能の開発を牽引しました。

## 課題

本コースにおける最大の課題は、プログラミング未経験者の受講生に、ICTの楽しさをいかに実感して頂くかという点でした。難しいプログラムの記述をすべて受講生に任せることは現実的ではなく、逆にインストラクターが全て記述してしまっては、参加者の主体性が失われてしまいます。そこで私は、実際のシステム開発におけるチームの役割分担を参考に、高校生が主体的に関与できる「ゲームバランスの調整」と「ゲームデザイン」の役割を参加者に任せる工夫をしました。

ゲームバランスの調節では、ゲームの裏側の仕組み作りをインストラクターである私が担い、数値の調整を高校生に任せています。例えば、2024年度に参加した際、難易度を調整する変数の設定を高校生に説明しつつ触っていただく事で、プログラミングの本質的な面白さを体験できるようにしました。

```javascript
// Easy モードの設定例 — 高校生がパラメータを調整・テストプレイした部分
if (mode === 'easy') {
    enemy_spown_time          = 60;   // 敵の出現間隔（フレーム数）
    strong_enemy_spown_time   = 150;  // 強敵の出現間隔
    strong_enemy_hobbor_frame = 120;  // 強敵がホバリングするフレーム数
    life                      = 5;    // プレイヤーのライフ
    remain_ballet             = 5;    // 残弾数
    enemy_norma               = 20;   // クリアに必要な撃破数
    remain_time               = 25;   // 制限時間（秒）
}
```

また、ゲームデザイン担当の生徒には、自ら考えた世界観に合わせてBGMや効果音、画像などの素材を選定してもらいました。指定したファイル名を実際のプログラムに組み込む工程を共に体験することで、ゲーム制作の全体像を実感できるように工夫しています。

これらの主体性を持たせる工夫の結果、参加した高校生から「ICT技術への関心が高まった」「プログラミングの面白さが分かった」という評価を多数頂きました。


## ## ゲームでの工夫点


### 2023年度

2023年度はインストラクター初年度であったため、まずは高校生に「ゲーム制作の流れ全体を体験してもらうこと」を最優先としました。あらかじめ用意されていたシューティングゲームのひな形をベースにしつつ、全方位から敵が出てくるスリルをプログラムで演出しました。その上で、BGMや効果音、敵キャラクターの画像といった素材を高校生と共に選定し、ゲームに組み込むことで、私自身もゲームデザインの基礎を学びつつ、高校生にゲームの楽しさを伝えました。

### 2024年度
2024年度は前年度の経験から得た知見を活かし、高校生の抽象的なアイデアを技術的に実現するための機能拡張の実装を頑張りました。例えば、「不規則で手強い敵を出したい」という要望に対しては、ただ直進するだけでなく、プレイヤーの位置を計算して賢く追いかけ、一定時間後に散開する敵の動きを数学的な計算を用いて新たに設計・実装しました。以下のコードのように、プレイヤーとの距離や方向を計算し、なめらかな追跡を実現しています。

```javascript
// 追尾フェーズ：プレイヤー方向へのベクトル正規化による移動
let deltaX = playerX - enemyX;
let deltaY = playerY - enemyY;
let distance = Math.sqrt(deltaX * deltaX + deltaY * deltaY);
enemy.x += (deltaX / distance) * enemySpeed;
enemy.y += (deltaY / distance) * enemySpeed;
```

他では、「やり込み要素と戦略性が欲しい」という声に応え、初心者向けのEasyから上級者向けのHard、さらに隠し要素の「裏モード」を加えた難易度調節システムを実装しました。また、シューティングゲームの駆け引きが、どうやって生まれるかを高校生と一緒に考え、弾数制限およびキー入力による「弾の補充（リロード）」の仕組みを導入しました。10種類の数値が難易度ごとに連動して変化する複雑な仕組みを設計し、無限に攻撃できる状態をなくすことで、駆け引きの要素を実現しています。さらに没入感を高めるため、ダメージを受けた際に画面を赤く光らせる演出や、難易度に応じたBGMの切り替え機能も実装しました。

## この経験で得たもの

このインストラクター経験を通じて、私は主に三つの力を養いました。

一つ目はプロジェクト推進力です。3泊4日という限られた期間の中で、企画の段階から実際にプレイできる完成品に至るまで、グループ全体をゴールへ導く経験を積みました。

二つ目は要件定義・設計力です。高校生から出てくるアイデアは抽象的なものが多く、漠然とした要望を、実装可能な仕様に落とし込む作業が求められました。この過程は、実際のシステムエンジニアがクライアントの要望を技術仕様に変換する業務と共通するものであり、SE的な視点を養う貴重な経験となりました。

三つ目はコミュニケーション力です。プログラミング未経験の高校生に対して、コードの意味や動作の仕組みをかみ砕いて説明し、ただ教えるのではなく主体的な参加を促せるような、相手の理解度に合わせて説明を調整する力が身につけることができました。
